# 库存偏差分析流程 (Gap检测)

## 目的
判断店铺后台库存是否与ERP实际可用量相符，找出偏差超过阈值的商品。

## 判断逻辑

读取 `Vkiau店铺折扣 库存 预售汇总5.18` 工作表中的以下三列：

| 列 | 字段 | 含义 |
|----|------|------|
| AA | 判断是否增加库存Gap200 | 店铺库存比ERP少200以上 → 需补货 |
| AB | 判断是否减少库存Gap200 | 店铺库存比ERP多200以上 → 需下架 |
| AC | 判断是否增加库存Gap1000 | 店铺库存比ERP少1000以上 → 严重缺货 |

## 输出

分别输出到3个子表：
1. **增加库存Gap200** — AA=TRUE 的所有行
2. **减少库存Gap200** — AB=TRUE 的所有行
3. **增加库存Gap1000** — AC=TRUE 的所有行

## 使用

```bash
python scripts/analyze.py --input "文件.xlsx" --output "结果.xlsx"
```
